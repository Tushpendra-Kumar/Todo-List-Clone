## 📌 Overview

A sleek, lightweight productivity task manager built with **Vanilla JavaScript**. Designed to help developers and students organize daily goals with local persistent storage and status filtering.

---

## ✨ Key Features

- **Persistent LocalStorage:** Tasks persist automatically across browser refreshes and device restarts.
- **Filter Controls:** View All tasks, Pending tasks, or Completed tasks with single-click tabs.
- **Task Completion Check:** Interactive strike-through styling and checkbox state toggling.
- **Quick Deletion & Clear All:** Delete individual completed tasks or flush the list with confirmation.

---

## 💻 Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript LocalStorage API
